# AML Homework 1

This folder contains the source code, datasets, prediction files for AML Homework 1.

## Source Code

- `housing.ipynb`: Jupyter notebook that completes all requirements of Part I of the Programming Exercises.
- `titanic.ipynb`: Jupyter notebook that completes all requirements of Part II of the Programming Exercises.

## House Prices Files

- `train.csv`: House Prices training dataset downloaded from Kaggle.
- `test.csv`: House Prices test dataset downloaded from Kaggle and used to generate predictions.
- `sample_submission.csv`: Sample submission file downloaded from Kaggle and used as a reference for the required output format.
- `data_description.txt`: Description of the House Prices variables downloaded from Kaggle.
- `submission_part1.csv`: Predictions generated by `housing.ipynb` for Kaggle submission.

## Titanic Files

- `titanic_train.csv`: Titanic training dataset downloaded from Kaggle. It contains the target variable `Survived`.
- `titanic_test.csv`: Titanic test dataset downloaded from Kaggle and used to generate predictions.
- `gender_submission.csv`: Sample Titanic submission file downloaded from Kaggle and used as a reference for the required output format.
- `titanic_submission.csv`: Predictions generated by `titanic.ipynb` for Kaggle submission.



## Running the Notebooks

Keep all CSV files in the same directory as the notebooks. Open the notebooks in Jupyter Notebook, JupyterLab, or a compatible editor and run the cells from top to bottom.
